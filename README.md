### RustingStudio

[RustingStudio](https://github.com/RustingStudio) is my org for rethinking old things with Rust and GPUs. Every project is pure Rust (or GLSL), no C++ build step, with the numbers measured and written down.

| Project | What it is | Headline |
| :--- | :--- | :--- |
| [**RustingStrata**](https://github.com/RustingStudio/RustingStrata) | MoE inference engine for Qwen3.5/3.6 GGUF. CPU+GPU hybrid experts, NVRTC CUDA kernels, OpenAI-compatible server. | Qwen3.6-35B-A3B on a 12 GB card: **2093 tok/s** prefill and **95.6 tok/s** decode, about 2x and 1.5x llama.cpp |
| [**RustingEngine**](https://github.com/RustingStudio/RustingEngine) | Game engine for huge physics scenes. Vulkan, Blender/Godot-style editor, hybrid CPU/GPU physics, deterministic replay. | **50,000 colliding GPU cubes at 119 FPS** |
| [**RustingBrain**](https://github.com/RustingStudio/RustingBrain) | Deep-learning library, from XOR to a 300M-param transformer on one GPU. Flash attention, MoE, mixed precision. | Ties or beats PyTorch `torch.compile` in training throughput |
| [**RustingShader**](https://github.com/RustingStudio/RustingShader) | Cinematic Iris shader pack for Minecraft. Volumetric skies, reflective water, PCSS shadows. | A gravitationally lensed black hole in the End |
| [**RustingScience**](https://github.com/RustingStudio/RustingScience) | Benchmarks, experiments and research notes on Rust, GPUs and ML. | [rustingstudio.github.io/science](https://rustingstudio.github.io/science) |
